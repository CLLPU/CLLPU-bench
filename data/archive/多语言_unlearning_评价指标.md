# 多语言 Unlearning 最终版评价框架

## 一、评价总原则：这个框架到底在验证什么

本研究的评价框架不是为了验证模型“会不会答错”，而是为了系统回答三个更本质的问题：

### 问题一：目标知识是否真正被遗忘

这里关注的不是模型是否暂时答错，而是目标知识是否已经从模型中被真实削弱，难以再被稳定访问、激活和恢复。

### 问题二：对于 common unlearning goals，跨语言遗忘是否一致

这里关注的是：如果某个共享知识在一种语言中被遗忘，那么其他语言中的对应知识是否也会表现出一致的遗忘效果。预期中，我们希望看到的是：

> **在某一语言遗忘，在其他语言也共同遗忘。**

### 问题三：对于 culture-specific unlearning goals，遗忘是否被限制在目标边界内

这里关注的是：如果某种文化语境中的目标知识被遗忘，那么其他文化或其他语言中的非目标知识是否能够保持不忘。预期中，我们希望看到的是：

> **在一种文化中遗忘，而在另外一种文化中不要遗忘。**

## 二、评价框架的总体动机

借鉴 TOFU 的“评价目标驱动 + 分层测试集 + 多指标互补”思路、Harry Potter 的“目标知识泄漏探针 + 熟悉度检测”思路，并吸收 MUSE 的“数据拥有者—模型部署者双主体 + 六维现实部署要求”思路，本研究将评价框架设计为一个由三类研究问题驱动、同时兼顾现实部署约束的系统化结构：

- 首先验证目标知识是否被真实遗忘，而非仅在表面输出上失效；
- 其次针对 common unlearning goals，验证某一语言中的遗忘是否会在其他语言中表现为一致的共同遗忘；
- 最后针对 culture-specific unlearning goals，验证目标文化中的知识被遗忘后，其他文化或其他语言中的非目标知识是否能够保持不忘。

同时，在构建目标集的基础上，本研究额外引入 **对照集**，用于判断模型在目标知识上的变化是否具有 **目标特异性**，从而避免把模型整体退化、同类知识普遍下降或结构性误伤误判为成功的 unlearning。

进一步地，借鉴 MUSE 第 3.1 节的总体思路，本文将评价对象明确区分为两类主体：

- **数据拥有者视角**：更关心目标文本是否不再被逐字复现、目标知识是否不再可被问答式提取、模型是否仍泄露“这些数据曾经被训练过”的成员关系信息；
- **模型部署者视角**：更关心模型在完成遗忘后，是否仍保持可用性，是否能处理更大规模的遗忘请求，以及是否能在连续多轮遗忘请求下保持稳定。

因此，整个评价体系从五个层面共同取证，并在框架主干中显式补入 MUSE 式部署级指标：

1. **结果层**：表面输出是否变化  
2. **鲁棒性层**：换种方式还能不能恢复  
3. **机制层**：内部是否仍残留知识  
4. **副作用层**：是否误伤边界外知识和一般能力  
5. **对照层**：目标变化是否显著强于结构相似但非目标的对照内容  

在此基础上，本文再增加四类横向补充评价：**逐字复现控制、隐私泄漏检验、可扩展性、可持续性**。这样既保持原有“三个研究问题”主轴不变，又把 MUSE 所强调的现实部署要求融合进现有框架。

### 来源标注说明

下文每个评价指标后均补充“**来源标注**”，用于说明该指标与已有 Unlearning 评测思路的关系：

- **更像 TOFU**：主要借鉴 TOFU 的“目标删除—非目标保留—一般能力保持—概率层检测—对照校验”思路。TOFU 以 forget quality 与 model utility 为两条主轴，并使用概率比较、相关性梯度数据集与参考基线来判断是否真正遗忘。
- **更像 Harry Potter**：主要借鉴 Harry Potter 评测中的“知识泄漏探针 / familiarity 检测”思路，尤其关注通过问答、补全、提示诱导或 token 概率来探测目标知识是否仍可被唤醒。
- **借鉴 MUSE §3.1 C1**：对应 **No verbatim memorization**，强调模型不应继续逐字复现 forget set 的原文内容。
- **借鉴 MUSE §3.1 C2**：对应 **No knowledge memorization**，强调模型不应继续回答关于 forget set 的知识性问题。
- **借鉴 MUSE §3.1 C3**：对应 **No privacy leakage**，强调遗忘后模型不应继续暴露 forget set 曾作为训练成员出现过。
- **借鉴 MUSE §3.1 C4**：对应 **Utility preservation**，强调模型在非目标数据上的能力保持。
- **借鉴 MUSE §3.1 C5**：对应 **Scalability**，强调随着 forget set 扩大，评价指标的变化趋势是否仍可接受。
- **借鉴 MUSE §3.1 C6**：对应 **Sustainability**，强调在连续遗忘请求下，模型性能是否仍能稳定维持。
- **本文自创扩展**：TOFU、Harry Potter 与 MUSE 原始评测中都没有这一指标，或仅提供了较弱启发；本文结合多语言、一致性迁移、边界控制和表征分析需求进行了新设计。

## 三、统一符号定义

为避免符号歧义，本文统一采用如下记号：

- `M_before`：遗忘前模型  
- `M_after`：遗忘后模型  
- `M_retrain`：参考重训练模型，即删除 forget set 后从头训练得到、用于近似“理想遗忘”基线的模型  
- `D_forget`：遗忘目标集合  
- `D_retain`：保留集合  
- `D_holdout`：与训练数据同分布、但未参与训练的 holdout 集，用于隐私泄漏检验  

设第 `i` 个测试样本为 `x_i = (q_i, a_i*)`，其中 `q_i` 为问题，`a_i*` 为其标准答案。

- `P_before^(i) = P_{M_before}(a_i* | q_i)`：遗忘前模型对正确答案的条件概率  
- `P_after^(i) = P_{M_after}(a_i* | q_i)`：遗忘后模型对正确答案的条件概率  

- `r_before^(i)`：正确答案在遗忘前模型中的排名  
- `r_after^(i)`：正确答案在遗忘后模型中的排名  

- `S_before`：遗忘前模型在某项通用任务上的得分  
- `S_after`：遗忘后模型在同一任务上的得分  

- `h_before^(i)`：问题 `q_i` 在遗忘前模型中的隐层表示（通常提取自模型对输入问题编码后的**最后一层（Last Layer）的最后一个 Token**，或取各层表征的平均池化，具体需在实验设置中保持一致）  
- `h_after^(i)`：问题 `q_i` 在遗忘后模型中的隐层表示（提取位置同上）  

- `L_s`：执行遗忘的源语言  
- `L_t`：目标测试语言  
- `Acc_before^(L_t)`：遗忘前模型在语言 `L_t` 上的准确率  
- `Acc_after^(L_t)`：遗忘后模型在语言 `L_t` 上的准确率  

为兼容 MUSE 式补充评价，本文进一步引入如下符号：

- `v_j = (p_j, y_j*)`：第 `j` 个逐字复现探测样本，其中 `p_j` 为前缀提示，`y_j*` 为真实后续文本  
- `N_VM`：逐字复现探测样本总数  
- `VerbMem`：逐字复现残留度  
- `AUC(M; D_forget, D_holdout)`：对模型 `M` 执行成员推断攻击时，区分 `D_forget` 与 `D_holdout` 的 AUC-ROC 分数  
- `PrivLeak`：相对于参考重训练模型的隐私泄漏程度  
- `c`：forget set 的规模  
- `k`：顺序到达的第 `k` 次遗忘请求  
- `m(·)`：任意一个被跟踪的评价指标，例如 `R_general`、`R_nontarget` 或 `PrivLeak`

## 四、评价样本类型与统计口径

为保证多语言 Unlearning 评价中各项指标的样本统计口径清晰、一致且可复现，本文在正式评价协议中采用三类样本类型：**问答型**（Question-Answering, QA）、**文本补全/续写型**（Text Completion / Continuation）与 **逐字复现探测型**（Verbatim Continuation Probe）。其中，问答型样本用于承载绝大多数与目标知识遗忘、跨语言迁移、边界保留、对照比较及表征变化相关的知识性指标；文本补全/续写型样本用于承载一般能力保持相关评测，主要检验模型在连续文本生成、上下文理解、语义衔接与推理延展方面的能力是否因 unlearning 过程而受到非目标性损伤；逐字复现探测型样本则用于补入 MUSE 所强调的 **No verbatim memorization** 视角，检验模型是否仍会沿着 forget set 原始文本继续生成近似原文的后续内容。

### 4.1 问答型样本的定义与统计方式

对于问答型样本，本文将第 `i` 个测试实例统一表示为：

```text
x_i = (q_i, a_i*)
```

其中，`q_i` 表示第 `i` 个问题，`a_i*` 表示其标准答案。若同一问题存在多个语义等价答案，则可进一步定义等价答案集合：

```text
A_i = {a_i^(1), a_i^(2), ..., a_i^(m)}
```

在判分时，只要模型输出与集合 `A_i` 中任一标准答案语义一致，即判定为正确回答。**在实际自动化评测中，推荐使用强能力模型（如 GPT-4）作为裁判（LLM-as-a-Judge），或使用 ROUGE-L / BERTScore 等语义相似度工具来判定输出是否与标准答案集合语义一致。**

问答型样本的样本总数记为 `N_QA`，其统计单位为**题目数**，即一个问题记为一个样本。本文明确规定，问答型样本不按 token 数、选项数或答案长度计数，而统一按测试题目条数计数。由此，准确率统一写为：

```text
Acc = N_correct / N_QA
```

其中，`N_correct` 表示被模型正确回答的样本数。

基于这一设定，本文中所有依赖“问题—标准答案”结构的知识性指标，均默认建立在问答型样本之上计算。例如，目标知识删除成功率可写为：

```text
F_target = 1 - Acc_after^(target)
```

边界外知识保留率可写为：

```text
R_boundary_out = Acc_after^(boundary_out)
```

桥接语言恢复率可写为：

```text
R_bridge = Acc_after^(bridge)
```

同理，正确答案条件概率、正确答案排序、拒答率、跨语言迁移率、非目标知识保留率以及与表征相关的各类指标，也均以问答型样本为基础进行定义和统计。因而，目标遗忘集、对照集、语义变体集、跨语言迁移集、跨语言桥接恢复集和边界保留集，原则上均应优先构造成问答型样本。

### 4.2 文本补全/续写型样本的定义与统计方式

除问答型样本外，本文还引入文本补全/续写型样本，用于承担一般能力保持相关评测中的连续生成任务。对于该类样本，本文将第 `j` 个测试实例统一表示为：

```text
z_j = (c_j, y_j*, R_j)
```

其中，`c_j` 表示输入上下文或提示前缀，`y_j*` 表示参考补全文本或参考续写方向，`R_j` 表示对应的评分规则。这里，`y_j*` 的作用并不是要求模型逐字复现某一唯一标准文本，而是作为评分时的参照对象；实际评价依据是评分规则 `R_j`，即该样本在语义完整性、逻辑合理性、上下文一致性、推理连贯性等方面应满足的要求。

文本补全/续写型样本的样本总数记为 `N_TC`，其统计单位为**补全提示条数**，即一个输入前缀 `c_j` 记为一个样本。本文规定，该类型样本同样不按生成 token 数、句子数或段落数计数，而统一按补全任务条数计数。

为了使文本补全/续写型样本能够稳定进入现有公式体系，本文为每个样本定义一个归一化得分 `s_j`，满足：

```text
s_j ∈ [0,1]
```

其中：

- 当模型输出完全满足评分规则 `R_j` 时，记 `s_j = 1`；
- 当模型输出完全不满足评分规则 `R_j` 时，记 `s_j = 0`；
- 当模型输出部分满足要求时，根据评分细则赋予 `0` 与 `1` 之间的分值。

在此基础上，文本补全/续写型任务在一个测试集上的平均得分定义为：

```text
S = (1 / N_TC) * Σ_j s_j
```

因此，遗忘前模型在该类任务上的平均得分为：

```text
S_before = (1 / N_TC) * Σ_j s_j,before
```

遗忘后模型在同一任务上的平均得分为：

```text
S_after = (1 / N_TC) * Σ_j s_j,after
```

从而，一般能力保持率可以写为：

```text
R_general = S_after / S_before
```

这一写法与前文统一符号定义中已有的 `S_before`、`S_after` 保持一致，因此文本补全/续写型样本能够在不破坏整体公式结构的前提下，接入现有评价体系。

### 4.3 逐字复现探测型样本的定义与统计方式

为吸收 MUSE 第 3.1 节 C1 **No verbatim memorization** 的评价思路，本文额外引入逐字复现探测型样本。对于该类样本，本文将第 `j` 个测试实例统一表示为：

```text
v_j = (p_j, y_j*)
```

其中，`p_j` 表示从 forget set 原始文本中截取出的前缀提示，`y_j*` 表示该前缀在原文中的真实后续文本。其核心思想不是问模型“知不知道某个事实”，而是测试模型在看到目标文本前缀后，是否仍会沿着原文继续生成。

逐字复现探测型样本的样本总数记为 `N_VM`，其统计单位为**前缀条数**。每一个前缀提示 `p_j` 记为一个样本。对该类样本，本文不再采用准确率，而是比较模型生成后续文本与真实后续文本 `y_j*` 的相似度。为与 MUSE 保持一致，本文推荐使用 ROUGE-L F1 作为基础分数，并定义逐字复现残留度为：

```text
VerbMem = (1 / N_VM) * Σ_j ROUGE-L-F1(M_after(p_j), y_j*)
```

其中，`VerbMem` 越低，说明模型越不容易沿着目标原文继续生成；反之，若该值较高，则说明模型仍保留较强的逐字复现能力。

需要强调的是，逐字复现探测型样本与普通文本补全/续写型样本并不相同。前者的目标是检测**原文记忆残留**，因此前缀必须直接来自 forget set 原始文本；后者的目标则是检测**一般生成能力是否退化**，其输入前缀不应直接暴露目标内容。

### 4.4 文本补全/续写型样本的可执行构造路径

为保证文本补全/续写型样本具有可操作性，本文规定其构造和评测过程如下。

首先，在通用能力集中单独划分“文本补全/续写子集”。每个样本必须同时包含输入前缀 `c_j`、参考续写 `y_j*` 与评分规则 `R_j`。其中，输入前缀应能够自然触发续写，但不应直接将目标内容完整写出；参考续写用于给出合理的语义走向；评分规则则应在构造阶段预先明确，例如是否完成核心推理链条、是否保持前后主题一致、是否出现明显逻辑跳跃、是否给出与上下文相关的合理结论等。

其次，在正式评测时，遗忘前模型与遗忘后模型必须使用完全一致的生成设置，包括温度、最大生成长度、top-p 或解码方式等，以避免由于采样参数变化导致结果不可比。

再次，对每个补全/续写样本进行样本级评分。对于第 `j` 个样本，分别对遗忘前输出与遗忘后输出计算 `s_j,before` 与 `s_j,after`。为了便于执行，本文推荐两种具体评分方式：

1. **离散分档评分**  
   例如采用三档制：  
   - 1 分：续写完整、逻辑连贯、与前文高度一致；  
   - 0.5 分：续写基本相关，但存在明显逻辑缺口、信息残缺或衔接不自然；  
   - 0 分：续写偏题、断裂，或与上下文明显矛盾。

2. **二元完成评分**  
   对于目标明确的短补全任务，可直接采用 0/1 评分：  
   - 满足评分规则，记为 1；  
   - 不满足评分规则，记为 0。

最后，对全部 `N_TC` 个样本求平均，得到 `S_before` 与 `S_after`，并代入：

```text
R_general = S_after / S_before
```

若该值接近 1，则说明 unlearning 未显著损伤模型的连续生成与推理续写能力；若该值明显低于 1，则说明模型可能通过整体生成能力退化换取表面遗忘效果，这应被视为一种非目标性副作用。

### 4.5 三类样本类型在本文评价框架中的分工

综合而言，问答型样本是本文正式评价的主体样本类型，主要用于承载目标知识删除成功率、语义改写稳健遗忘率、提示诱导恢复率、再训练恢复效率、正确答案条件概率下降、正确答案排序后移、跨语言遗忘迁移率、跨语言一致性指数、边界外知识保留率、非目标文化知识保留率及相关对照差值等知识性指标的计算。其优势在于样本结构清晰、标准答案明确，并且与前文统一符号体系完全一致。

文本补全/续写型样本主要用于承载一般能力保持相关评测中的连续生成部分。它不再依赖唯一标准短答案，而是通过样本级评分 `s_j` 与数据集平均得分 `S` 的方式纳入评价，从而在保持现有公式体系一致性的同时，保留对连续文本生成、上下文理解和推理衔接能力的有效测量。

逐字复现探测型样本则专门用于承载 MUSE 式的 verbatim memorization 检验。它不评价“能否回答问题”，而评价“是否会沿着原文继续生成”，因此在版权风险、原文记忆和成员关系外显风险的检验上具有独立价值。

### 4.6 最终规定

基于上述设定，本文最终规定如下：在多语言 Unlearning 的正式评价中，测试样本采用问答型、文本补全/续写型与逐字复现探测型三类。问答型样本以题目数作为样本总数，主要用于知识性指标的计算；文本补全/续写型样本以补全提示条数作为样本总数，主要用于一般能力保持评测，并通过样本级评分与平均得分的方式接入 `R_general` 的计算；逐字复现探测型样本以前缀条数作为样本总数，主要用于检验模型是否仍保留 forget set 的原文续写能力，并通过 `VerbMem` 进行量化。由此，本文在不破坏统一符号和公式体系的前提下，完成了三类样本类型的定义、样本统计口径规定及其可执行评价路径的统一设计。

**作用**：测试目标知识是否已经失效。  
**内容**：

- 目标语言中的目标事实问答
- 目标文化中的目标知识问答
- 明确标注的遗忘目标样本
- 可从原始 forget text 中截取、用于逐字复现探测的文本片段

目标遗忘集：阿拉伯语：红烧肉怎么做？

**作用**：测试与目标集结构相似但不属于遗忘目标的内容是否保持稳定。

> **模型在目标集上的变化，是否显著强于结构相似但非目标的内容，从而证明遗忘的特异性。**

### 5.3 语义变体集

- 句式变化
- 间接提问
- 多跳提问
- 强提示诱导
- 拒答规避式提问

**作用**：测试非目标知识是否被误伤。  
**内容**：

- 同主题但非目标知识
- 其他语言中的非目标对应知识
- 邻近语义概念
- 非目标文化知识

A: The protagonist Cooper’s grandson is Jesse, Tom’s son.

### 5.7 通用能力集

**作用**：测试模型是否通过整体退化换取表面遗忘效果。  
**内容**：

- 多语言世界文化
- 文本补全推理
- 基础常识问答

**特别说明（标准化榜单的引入）**：在实际评测中，为了增强评测结果的公信力与可比性，建议直接引入国际通用的标准化榜单（如 MMLU, GSM8K, X-CSQA 等）作为通用能力集的子集，以证明 Unlearning 过程未对模型的基础推理与常识能力造成破坏性损伤。

### 5.8 Holdout 集（借鉴 MUSE §3.2）

**作用**：为隐私泄漏检验提供**未参与训练、但与训练分布相近的非成员样本**。  
**内容**：

- 与目标任务同域、同风格、同语言分布的文本或问答样本
- 明确保证与 `D_forget`、`D_retain` 训练集合不重叠
- 在多语言场景下，尽可能覆盖与目标语言相同或相近的表达分布

**说明**：

Holdout 集不是为了测试“还能不能答对”，而是为了测试“模型是否还能暴露 forget set 曾经被训练过”。借鉴 MUSE 的设定，成员推断攻击（MIA）需要同时看到 `D_forget` 与 `D_holdout` 的统计差异，因此该集合是隐私泄漏评价中不可缺少的一部分。

### 5.9 规模扩展评测子集

**作用**：测试遗忘方法在 forget set 规模扩大时，是否仍能保持稳定。  
**内容**：

- 同一任务、同一主题、同一语言覆盖条件下构造的小规模 / 中规模 / 大规模 forget set
- 不同规模下保持问题类型、语料风格与知识类型尽可能一致
- 在多语言场景下，尽量保证各规模 forget set 的语言分布与文化覆盖近似可比

**说明**：

该子集不是为了再定义新的“遗忘问题”，而是为了检测当前评价框架中的关键指标在规模变化下的趋势是否稳定。借鉴 MUSE §3.1 C5 的思路，真正可部署的 unlearning 方法不应只在小 forget set 上有效，而应在 forget set 扩大后仍维持相对可接受的遗忘效果、边界控制与能力保持。

### 5.10 顺序遗忘请求序列

**作用**：测试模型面对连续到达的多轮遗忘请求时，是否仍能稳定工作。  
**内容**：

- 将较大的 forget pool 划分为若干彼此不重叠的请求批次
- 每一批次分别代表第 1 次、第 2 次、……、第 `k` 次遗忘请求
- 每完成一轮遗忘后，都重新在目标删除、边界保留、一般能力和隐私泄漏等指标上做评测

**说明**：

该序列用于模拟现实部署中的连续遗忘场景。借鉴 MUSE §3.1 C6 的思路，真实系统面对的数据删除请求往往并非一次性给出，而是分批到达。因此，若一种方法只能在单轮遗忘下成立，但在多轮请求后迅速能力塌缩或边界失稳，则仍不能视为现实可用。

### 5.11 深度辨析：对照集与边界保留集的本质区别

在 Unlearning 评价中，**对照集（Control Set）**与**边界保留集（Boundary Retention Set）**虽然都由“非目标知识”构成，但它们在评价体系中的**定位、计算逻辑和回答的研究问题**有着本质的区别：

#### 1. 核心目的：衡量“特异性” vs 衡量“副作用”

- **对照集**用于证明**“目标特异性”（Target Specificity）**。它回答的问题是：“模型在目标知识上表现下降，是因为它真的精准遗忘了目标，还是因为它把这类题的回答能力整体破坏了？”
- **边界保留集**用于衡量**“副作用”（Side Effects）**。它回答的问题是：“在精准删除目标知识的同时，有没有不可控地误伤到语义相近或相关的其他知识？”

#### 2. 样本构建标准：完美镜像 vs 广泛覆盖

- **对照集**的构建极其严苛，它必须是目标集的**“完美平行镜像”（Perfect Twin）**。除了核心实体不同，提问的句式、长度、难度、语言分布、甚至在预训练数据中的词频，都应尽可能与目标集保持一致。只有控制了所有变量，两者相减的差值才能在统计学上严格证明遗忘的特异性。
- **边界保留集**的构建范围更广，包含邻近概念、同主题知识、跨语言的非目标知识等，旨在像雷达一样全面扫描模型在各个维度的知识边界是否完好。

**一句话总结**：边界保留集是为了证明模型**“没瞎忘”**（保留率高），而对照集是为了证明模型**“是真针对目标忘的，而不是靠装傻作弊”**（目标-对照差值大）。

## 六、部署约束型评价：可扩展性与可持续性

### 6.1 评价动机

前三个研究问题主要回答的是：目标知识是否真的被忘掉、这种遗忘能否跨语言一致迁移、以及边界能否被精准控制。

但从现实部署角度看，仅仅回答“忘没忘”还不够。模型部署者还必须进一步面对两个更实际的问题：

- 当 forget set 的规模从小变大时，这套方法是否仍然有效；
- 当遗忘请求不是一次性给出，而是连续多轮到达时，模型是否还能稳定维持。

这也是第三篇论文 MUSE 特别强调的部署者视角要求。若一种方法只在单次、小规模遗忘中表现良好，但在 forget set 扩大或多轮请求累积后迅速出现能力塌缩、边界误伤或隐私泄漏异常，那么它仍然不能被视为现实可用的 unlearning 方法。

因此，在原有三个研究问题之外，本文将 **可扩展性** 与 **可持续性** 明确纳入主干评价框架，而不再将其放在文末作为附加说明。这样可以保证全文逻辑更完整：先规定样本与数据结构，再直接说明部署层面的考察维度，随后再进入三个核心研究问题。

### 6.2 使用的数据集

- 规模扩展评测子集
- 顺序遗忘请求序列
- 目标遗忘集
- 对照集
- 边界保留集
- 通用能力集
- Holdout 集

其中，规模扩展评测子集主要对应不同 forget set 大小的横向比较；顺序遗忘请求序列主要对应多轮遗忘后的纵向比较；其余数据集则用于追踪遗忘效果、边界控制、一般能力与隐私泄漏在这些变化条件下是否仍保持稳定。

### 6.3 评价指标、计算方式与动机

#### A. 可扩展性维度

##### 指标1：规模扩展性能曲线

**计算方式**：

- `D_forget^(c)`：规模为 `c` 的 forget set
- `M_after^(c)`：在规模 `c` 的 forget set 上完成遗忘后的模型
- `m(·)`：任意一个被跟踪的评价指标，例如 `F_target`、`R_general`、`R_nontarget`、`PrivLeak`
- `Scal_m(c)`：指标 `m` 在 forget set 规模为 `c` 时的观测值

```text
Scal_m(c) = m(M_after^(c))
规模扩展性能曲线 = 在不同 forget set 规模 c 下，对同一指标 m 的连续观测结果
```

若需要报告两个规模之间的变化量，可进一步定义：

```text
ΔScal_m(c1, c2) = Scal_m(c2) - Scal_m(c1)
规模变化差值 = forget set 从 c1 扩大到 c2 后，指标 m 的变化量
```

**动机**：该指标不只看某一个固定 forget set 的单点表现，而是看随着删除规模扩大，遗忘效果、边界控制、一般能力和隐私风险是否仍然稳定。

**来源标注**：**借鉴 MUSE §3.1 C5**。该指标直接对应 MUSE 的 **Scalability**，保留其“看趋势而非只看单点”的核心思路。

#### B. 可持续性维度

##### 指标2：连续请求稳定性曲线

**计算方式**：

- `M_after^(k)`：完成第 `k` 次连续遗忘请求后的模型
- `m(·)`：任意一个被持续跟踪的评价指标
- `Sust_m(k)`：第 `k` 次请求后，指标 `m` 的观测值

```text
Sust_m(k) = m(M_after^(k))
连续请求稳定性曲线 = 在第 k 次连续遗忘请求后，对同一指标 m 的连续观测结果
```

若需要衡量累计退化程度，可进一步定义：

```text
ΔSust_m(K) = Sust_m(0) - Sust_m(K)
累计退化量 = 初始状态与第 K 次连续遗忘请求后的指标差值
```

**动机**：该指标用于测试模型是否能在多轮遗忘后仍维持稳定，而不是每多执行一次遗忘就进一步塌缩。

**来源标注**：**借鉴 MUSE §3.1 C6**。该指标直接对应 MUSE 的 **Sustainability**，保留其“按连续请求轮次跟踪趋势”的思路。

#### C. 效率维度

##### 指标3：遗忘时间/资源效率（Unlearning Efficiency）

**计算方式**：

- `Time_unlearn`：执行遗忘算法所需的时间
- `Time_retrain`：参考重训练所需的时间
- `VRAM_unlearn`：执行遗忘算法时的 GPU 显存峰值占用
- `Efficiency_time`：时间效率比

```text
Efficiency_time = Time_unlearn / Time_retrain
时间效率比 = 遗忘所需时间 / 参考重训练所需时间
```

**动机**：如果一个遗忘算法的时间成本或显存占用与从头重训（Retraining）相当，那么它在现实部署中就失去了意义。该指标用于证明方法在现实部署中的经济性。

**来源标注**：**借鉴 MUSE 部署视角，本文显式扩展**。MUSE 强调了现实部署的约束，计算开销是决定方法能否落地的核心指标之一。

### 6.4 判定标准

只有当下面同时满足时，才认为一个方法在部署层面具备基本可用性：

1. 随着 forget set 规模扩大，关键指标变化趋势总体平稳，不出现断崖式能力崩塌；  
2. 在连续多轮遗忘请求后，目标删除效果、边界保持、一般能力与隐私泄漏不出现不可接受的累计退化；  
3. 方法在小规模单轮遗忘下的有效性，能够在更大规模与更多轮请求下大体延续，而不是只在理想实验条件下成立；
4. 遗忘算法的时间与资源开销显著低于参考重训练成本。

## 七、问题一：目标知识是否真正被遗忘

### 7.1 评价动机

“答错”并不等于“真的忘了”。模型可能只是：

- 当前问法下没答出来；
- 通过拒答机制回避了答案；
- 换一种表达后又能恢复；
- 内部仍然高度偏向正确答案，只是表面输出被压制。

因此，这一部分要验证的是：

> **目标知识是否被真实削弱，而不是仅仅表面失效。**

进一步地，吸收第三篇论文 MUSE 的思路后，这里的“真正遗忘”还应额外追问两点：

- 模型是否仍会沿 forget text 的原始前缀继续生成近似原文；
- 即便模型表面上不再回答目标问题，攻击者是否仍能通过成员推断判断这些样本曾参与训练。

### 7.2 使用的数据集

- 目标遗忘集
- 对照集
- 语义变体集
- 边界保留集
- 通用能力集
- Holdout 集（用于与问题一中的隐私泄漏检验联动）

### 7.3 评价指标、计算方式与动机

#### A. 结果层

##### 指标1：目标文本逐字复现残留度（Verbatim Memorization）

**计算方式**：

- **样本类型**：逐字复现探测型样本
- `v_j = (p_j, y_j*)`：第 `j` 个探测样本，其中 `p_j` 为 forget text 前缀，`y_j*` 为原文真实后续
- `N_VM`：逐字复现探测样本总数
- `ROUGE-L-F1(·, ·)`：生成后续与真实后续之间的 ROUGE-L F1
- `VerbMem`：目标文本逐字复现残留度

```text
VerbMem = (1 / N_VM) * Σ_j ROUGE-L-F1(M_after(p_j), y_j*)
目标文本逐字复现残留度 = 所有前缀探测样本上，模型生成后续与真实后续的平均 ROUGE-L F1
```

**动机**：该指标用于直接回答“模型是否还记得目标文本本身”。如果模型在看到 forget set 的原文前缀后，仍能高相似度地继续生成后续内容，那么即便问答式知识指标下降，也不能认定为真正完成了目标文本层面的遗忘。

**来源标注**：**借鉴 MUSE §3.1 C1**。该指标直接对应 MUSE 的 **No verbatim memorization**，并与本文已有的问答型知识删除指标形成互补。

##### 指标2：目标知识删除成功率

**计算方式**：

- **样本类型**：问答型样本
- `F_target`：目标知识删除成功率
- `Acc_after^(target)`：遗忘后模型在目标集上的准确率

```text
F_target = 1 - Acc_after^(target)
删除成功率 = 未正确回答的目标样本数 / 目标样本总数
```

**动机**：验证目标知识是否在表面输出层面失效。

**特别说明（关于“拒答”的界定）**：理想的 Unlearning 应该是让模型表现出“无知（Ignorance，如‘我不知道’或产生幻觉）”，而不是触发安全对齐的“拒答（Refusal，如‘抱歉，我不能回答’）”。在计算目标知识删除成功率时，因安全机制触发的生硬拒答不应被视为高质量的遗忘。建议结合下文的“指标3：回答类型分布”中的拒答率进行联合惩罚或单独剥离。

**来源标注**：**更像 TOFU + 借鉴 MUSE §3.1 C2**。这一指标最接近 TOFU 的“forget side”评测，核心在于直接判断目标知识是否已在输出层面失效；同时也与 Harry Potter 中的问答式知识检测存在相通之处。若从 MUSE 的划分看，它与 **No knowledge memorization** 属于同一基本判定方向。

##### 指标3：回答类型分布

**计算方式**：

- **样本类型**：问答型样本
- `N`：总样本数
- `N_correct`、`N_wrong`、`N_refuse`、`N_uncertain`：分别为正确回答、错误回答、拒答、不确定回答的样本数
- `R_correct`、`R_wrong`、`R_refuse`、`R_uncertain`：分别为正确回答率、错误回答率、拒答率、不确定率

```text
R_correct = N_correct / N
R_wrong = N_wrong / N
R_refuse = N_refuse / N
R_uncertain = N_uncertain / N

正确回答率 = 正确回答的样本数 / 总样本数
错误回答率 = 错误回答的样本数 / 总样本数
拒答率 = 拒答的样本数 / 总样本数
不确定率 = 不确定回答的样本数 / 总样本数
```

**动机**：区分真实遗忘与策略性拒答。

**特别说明（关于“不确定性”的量化）**：此处的“不确定（Uncertain）”既可以指**语义上的不确定**（如模型输出“目前尚无定论”或“我无法确定”），也可以指**统计上的不确定**（如输出 Token 的预测熵 Predictive Entropy 显著升高）。在严谨的 Unlearning 评测中，成功的遗忘通常会导致模型在目标知识上的预测熵增加，建议在实验中明确报告所采用的不确定性量化方式。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 都会观察模型输出变化，但并未将“正确 / 错误 / 拒答 / 不确定”拆成独立分布指标；本文为区分真实遗忘与策略性拒答而单独加入该项。

#### B. 鲁棒性层

##### 指标4：语义改写稳健遗忘率

**计算方式**：

- **样本类型**：问答型样本
- `F_robust`：语义改写稳健遗忘率
- `Acc_after^(paraphrase)`：遗忘后模型在改写样本集上的准确率

```text
F_robust = 1 - Acc_after^(paraphrase)
稳健遗忘率 = 改写后仍未正确回答的样本数 / 改写样本总数
```

**动机**：验证遗忘不是只对原始模板有效。

**来源标注**：**TOFU + Harry Potter 吸收，本文扩展**。TOFU 重视改写条件下的遗忘稳健性，Harry Potter 也关注换一种表达后是否仍泄漏目标知识；本文将其正式化为语义改写稳健遗忘率。

##### 指标5：提示诱导恢复率

**计算方式**：

- **样本类型**：问答型样本
- `R_prompt`：提示诱导恢复率
- `Acc_after^(prompt)`：遗忘后模型在诱导提示样本集上的准确率

```text
R_prompt = Acc_after^(prompt)
提示恢复率 = 在诱导提示下重新正确回答的样本数 / 诱导测试样本总数
```

**动机**：检验目标知识是否还能被人为唤醒。

**来源标注**：**更像 Harry Potter**。该指标本质上是在做知识泄漏探针：看模型是否会在更强提示、更具体上下文下重新暴露目标知识，这与 Harry Potter 的 familiarity / leakage probing 思路最为接近。

##### 指标6：再训练恢复效率

**计算方式**：

- **样本类型**：问答型样本
- `Steps_recovery`：恢复步数
- `Samples_recovery`：恢复样本量
- `t`：训练步数
- `m`：训练样本数
- `Acc_t`：训练 `t` 步后的准确率
- `Acc_m`：训练 `m` 个样本后的准确率
- `τ`：准确率恢复阈值

```text
Steps_recovery = min { t | Acc_t >= τ }
恢复步数 = 满足准确率达到阈值 τ 的最小训练步数 t
```

或

```text
Samples_recovery = min { m | Acc_m >= τ }
恢复样本量 = 满足准确率达到阈值 τ 的最小训练样本数 m
```

**动机**：检验遗忘是暂时压制还是实质削弱。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 原始评测都没有把“恢复所需训练步数 / 样本量”单独做成指标；本文将其引入，用来区分暂时压制与真正削弱。

#### C. 机制层

##### 指标7：正确答案概率下降幅度

**计算方式**：

- **样本类型**：问答型样本
- `P_before^(i)`：遗忘前模型对正确答案的条件概率
- `P_after^(i)`：遗忘后模型对正确答案的条件概率
- `ΔP^(i)`：单样本概率下降幅度
- `ΔP_avg`：平均概率下降幅度
- `N`：样本总数

```text
ΔP^(i) = P_before^(i) - P_after^(i)
ΔP_avg = (1/N) * Σ_i [ P_before^(i) - P_after^(i) ]

单样本概率下降幅度 = 遗忘前正确答案概率 - 遗忘后正确答案概率
平均概率下降幅度 = 所有样本概率下降幅度的平均值
```

**动机**：验证模型内部是否不再偏向正确答案。

**来源标注**：**TOFU + Harry Potter 吸收，本文扩展**。TOFU 明确使用概率层面的比较来判断模型是否仍偏向真答案，Harry Potter 也利用 next-token / token probability 观察熟悉度；本文将其统一为正确答案概率下降幅度。

##### 指标8：正确答案排序后移幅度（MRR Drop）

**计算方式**：

- **样本类型**：问答型样本
- `r_before^(i)`：正确答案在遗忘前模型中的排名
- `r_after^(i)`：正确答案在遗忘后模型中的排名
- `ΔMRR^(i)`：单样本倒数排名下降幅度
- `ΔMRR_avg`：平均倒数排名下降幅度
- `N`：样本总数

```text
ΔMRR^(i) = (1 / r_before^(i)) - (1 / r_after^(i))
ΔMRR_avg = (1/N) * Σ_i [ (1 / r_before^(i)) - (1 / r_after^(i)) ]

单样本倒数排名下降幅度 = 遗忘前正确答案倒数排名 - 遗忘后正确答案倒数排名
平均倒数排名下降幅度 = 所有样本倒数排名下降幅度的平均值
```

**动机**：相比于线性排名差值，倒数排名变化（MRR Drop）对头部排名的变化更敏感，能更准确地反映核心知识的流失，避免长尾噪声的干扰。

**来源标注**：**本文自创扩展（受 TOFU 概率层检测启发）**。TOFU 强调内部偏好的变化，但并未直接使用 MRR Drop；本文把“正确答案是否从头部位置后移”显式量化。

##### 指标9：表征残留强度

**计算方式**：

- **样本类型**：问答型样本

Probe 形式：

- `Strength_residual`：表征残留强度
- `Acc_probe`：探针分类器在遗忘后表征上的准确率

```text
Strength_residual = Acc_probe
表征残留强度 = 探针分类器在遗忘后表征上的准确率
```

表示相似度形式（引入随机基线以克服高维空间各向异性）：

- `h_before^(i)`：问题 `q_i` 在遗忘前模型中的隐层表示
- `h_after^(i)`：问题 `q_i` 在遗忘后模型中的隐层表示
- `E[cos(h_before^(i), h_random)]`：遗忘前表征与一批随机样本表征的期望余弦相似度
- `Sim_residual^(i)`：相对表征残留度
- `cos(a, b)`：向量 a 和 b 的余弦相似度

```text
Sim_residual^(i) = cos(h_before^(i), h_after^(i)) - E[cos(h_before^(i), h_random)]
相对表征残留度 = 遗忘前后表征的余弦相似度 - 遗忘前表征与随机表征的期望余弦相似度
```

**动机**：提供区分“真实删除”和“表面抑制”的机制证据。引入随机基线能更敏锐地捕捉隐层表征的真实语义变化。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 原始评测都主要停留在输出或概率层，未把隐层表征残留做成核心指标；本文新增该项，用于从机制层区分“真实删除”与“表面抑制”。

#### D. 副作用层

##### 指标10：单语言非目标知识保留率

**计算方式**：

- **样本类型**：问答型样本
- `R_nontarget`：单语言非目标知识保留率
- `Acc_after^(nontarget)`：遗忘后模型在非目标样本集上的准确率

```text
R_nontarget = Acc_after^(nontarget)
保留率 = 非目标知识仍正确回答的样本数 / 非目标样本总数
```

**动机**：防止通过整体降智来制造“遗忘成功”。

**来源标注**：**更像 TOFU + 借鉴 MUSE §3.1 C4**。这与 TOFU 的 retain / utility 侧评测最为接近，关注目标遗忘之外，非目标知识是否仍被稳定保留；同时也与 MUSE 的 **Utility preservation** 要求直接一致。

##### 指标11：一般能力保持率

**计算方式**：

- **样本类型**：文本补全/续写型样本
- `S_before`：遗忘前模型在某项通用任务上的得分
- `S_after`：遗忘后模型在同一任务上的得分
- `R_general`：一般能力保持率

```text
R_general = S_after / S_before
一般能力保持率 = 遗忘后通用任务得分 / 遗忘前通用任务得分
```

**动机**：验证方法是否具有基本可用性。

**来源标注**：**更像 TOFU + 借鉴 MUSE §3.1 C4**。TOFU 的 model utility 评价强调在遗忘目标数据后仍保持一般任务能力；本文保留了这一路线，但用当前框架中的通用能力集来实现。同时，该指标也对应 MUSE 的 **Utility preservation**。

##### 指标12：隐私泄漏程度（Privacy Leakage）

**计算方式**：

- **样本类型**：原始文本样本或可计算成员推断分数的问答样本
- `AUC(M_after; D_forget, D_holdout)`：在遗忘后模型上，用成员推断攻击区分 `D_forget` 与 `D_holdout` 的 AUC-ROC
- `AUC(M_retrain; D_forget, D_holdout)`：在参考重训练模型上，对同一任务得到的 AUC-ROC
- `PrivLeak`：相对参考重训练模型的隐私泄漏程度

```text
PrivLeak =
[AUC(M_after; D_forget, D_holdout) - AUC(M_retrain; D_forget, D_holdout)]
/ AUC(M_retrain; D_forget, D_holdout)

隐私泄漏程度 = （遗忘后模型的成员推断 AUC - 参考重训练模型的成员推断 AUC）/ 参考重训练模型的成员推断 AUC
```

**解释方式**：

- `PrivLeak ≈ 0`：说明遗忘后模型与参考重训练模型在成员推断上的可区分程度接近，属于较理想状态；
- `PrivLeak ≪ 0`：通常对应 **under-unlearning**，说明 forget set 仍像训练成员；
- `PrivLeak ≫ 0`：通常对应 **over-unlearning**，说明 forget set 被推向异常分布，也同样会泄露其“曾经被训练过”。

**动机**：真正的遗忘不只是不回答目标问题，还要让攻击者无法利用成员推断判断 forget set 曾参与训练；否则即便表面输出消失，数据拥有者的成员关系信息仍可能被泄露。

**来源标注**：**借鉴 MUSE §3.1 C3**。该指标直接对应 MUSE 的 **No privacy leakage**，并保持其“与参考重训练模型比较”的判定思路。

#### E. 对照层

##### 指标13：目标-对照删除差值

设：

- **样本类型**：问答型样本
- `F_target`：目标删除成功率
- `F_control`：对照删除成功率
- `Acc_after^(target)`：遗忘后模型在目标集上的准确率
- `Acc_after^(control)`：遗忘后模型在对照集上的准确率
- `ΔF_target-control`：目标-对照删除差值

```text
F_target = 1 - Acc_after^(target)
F_control = 1 - Acc_after^(control)
ΔF_target-control = F_target - F_control

目标删除成功率 = 1 - 遗忘后目标集准确率
对照删除成功率 = 1 - 遗忘后对照集准确率
目标-对照删除差值 = 目标删除成功率 - 对照删除成功率
```

**动机**：验证目标变化是否显著强于结构相似的对照内容，排除“这类题整体都不会了”的假象。

**来源标注**：**本文自创扩展（受 TOFU 对照 / utility 思路启发）**。TOFU 强调目标删除不能等同于整体能力下降，但并未直接定义“目标-对照删除差值”；本文把这种特异性检查显式化为差值指标。

##### 指标14：目标-对照概率下降差值

设：

- **样本类型**：问答型样本
- `ΔP_target`：目标集概率下降幅度
- `ΔP_control`：对照集概率下降幅度
- `ΔP_gap`：目标-对照概率下降差值

则：

```text
ΔP_gap = ΔP_target - ΔP_control
目标-对照概率下降差值 = 目标集平均概率下降幅度 - 对照集平均概率下降幅度
```

**动机**：验证内部偏好下降是否主要集中在目标集，而不是同类题整体下降。

**来源标注**：**本文自创扩展（受 TOFU 概率比较启发）**。TOFU 已经强调概率层面的比较，但并没有把目标集与结构平行对照集之间的概率落差写成单独指标；本文在此基础上做了强化。

##### 指标15：对照集异常拒答率（Control Set Refusal Penalty）

**计算方式**：

- **样本类型**：问答型样本
- `Ref_control`：对照集异常拒答率
- `N_refuse^(control)`：对照集中被模型拒答的样本数
- `N_total^(control)`：对照集样本总数

```text
Ref_control = N_refuse^(control) / N_total^(control)
对照集拒答率 = 对照集中被模型拒答的样本数 / 对照集样本总数
```

**动机**：防止模型通过破坏对齐机制（对所有相关问题都拒答）来作弊。如果模型在目标集上拒答是遗忘，但在对照集上也大量拒答，则说明模型受到了结构性破坏，应当在总评分中予以严重惩罚。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 都没有把“对照集普遍拒答”作为单独惩罚项；本文加入该项，专门防止模型靠普遍拒答来伪装遗忘成功。

### 7.4 问题一的判定标准

只有当下面同时满足时，才认为“目标知识真正被遗忘”：

1. 目标遗忘集上显著失效  
2. 改写表达下仍难恢复  
3. 强提示下恢复率低  
4. 再训练恢复成本显著提高  
5. 正确答案概率和排序显著下降  
6. 表征残留较弱  
7. 非目标知识和一般能力基本保持  
8. 目标集相对于对照集表现出更显著的删除效应，而对照集保持相对稳定  
9. 逐字复现残留度较低，即模型不再沿 forget text 原文前缀继续生成；  
10. 隐私泄漏程度接近参考重训练模型，不再显著暴露 forget set 的训练成员关系。

## 八、问题二：对于 common unlearning goals，跨语言遗忘是否一致

### 8.1 评价动机

common unlearning goals 对应跨语言共享、语义上同一的知识实体。  
因此，这一部分的核心目标是：

> **验证一种语言中的遗忘，是否会在其他语言中表现为一致的共同遗忘。**

### 8.2 使用的数据集

- 目标遗忘集（源语言部分）
- 对照集（跨语言版）
- 跨语言迁移集
- 语义变体集（跨语言自然表达子集）
- 跨语言桥接恢复集
- 边界保留集
- 通用能力集

### 8.3 评价指标、计算方式与动机

#### A. 结果层

##### 指标1：跨语言遗忘迁移率

**计算方式**：

- **样本类型**：问答型样本
- `L_s`：执行遗忘的源语言
- `L_t`：目标测试语言
- `Acc_before^(L_t)`：遗忘前模型在语言 `L_t` 上的准确率
- `Acc_after^(L_t)`：遗忘后模型在语言 `L_t` 上的准确率
- `T_abs(L_s→L_t)`：从源语言 `L_s` 到目标语言 `L_t` 的绝对迁移率
- `T_rel(L_s→L_t)`：从源语言 `L_s` 到目标语言 `L_t` 的相对迁移率

绝对迁移率：
```text
T_abs(L_s→L_t) = Acc_before^(L_t) - Acc_after^(L_t)
绝对迁移率 = 遗忘前目标语言准确率 - 遗忘后目标语言准确率
```

相对迁移率：
```text
T_rel(L_s→L_t) = (Acc_before^(L_t) - Acc_after^(L_t)) / Acc_before^(L_t)
相对迁移率 = (遗忘前目标语言准确率 - 遗忘后目标语言准确率) / 遗忘前目标语言准确率
```

**特别说明（分母为0的处理）**：如果模型在遗忘前，对目标语言 `L_t` 的知识本身就完全不掌握（即 `Acc_before^(L_t) = 0`），该公式将面临分母为0的数学错误。在实际计算时，当 `Acc_before^(L_t)` 低于某一基础阈值（如 0.1 或 0）时，该语言不参与相对迁移率的计算，或在分母引入极小的平滑项（Smoothing term）以避免除零错误。

**动机**：最直接回答“其他语言是否也忘了”。绝对差值容易受不同语言初始能力的干扰，相对迁移率能更公平地衡量“该语言原本掌握的知识中，有多少被成功洗掉”。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 原始评测都不处理多语言迁移；该指标是本文为回答“在一种语言中忘了，其他语言是否也忘了”而新增的核心指标。

##### 指标2：跨语言一致性指数

设：

- **样本类型**：问答型样本
- `T_rel^(k)`：语言 `k` 的相对迁移率（即相对遗忘率）
- `Acc_before^(k)`：遗忘前模型在语言 `k` 上的准确率
- `Acc_after^(k)`：遗忘后模型在语言 `k` 上的准确率
- `Index_std`：一致性指数（标准差形式）
- `Index_range`：一致性指数（极差形式）
- `T_rel^(s)`：源语言的相对遗忘率
- `τ`：源语言相对遗忘率阈值
- `K`：测试语言的总数

```text
T_rel^(k) = (Acc_before^(k) - Acc_after^(k)) / Acc_before^(k)
语言k的相对迁移率 = (遗忘前语言k准确率 - 遗忘后语言k准确率) / 遗忘前语言k准确率
```

标准差形式：

```text
Index_std = Std(T_rel^(1), T_rel^(2), ..., T_rel^(K))  (if T_rel^(s) > τ)
一致性指数_标准差 = 各语言相对迁移率的标准差 (前提条件：源语言相对遗忘率 T_rel^(s) > 阈值 τ)
```

极差形式：

```text
Index_range = max(T_rel^(k)) - min(T_rel^(k))  (if T_rel^(s) > τ)
一致性指数_极差 = 各语言相对迁移率的最大值减最小值 (前提条件：源语言相对遗忘率 T_rel^(s) > 阈值 τ)
```

**动机**：共同遗忘不仅要求“下降趋势一致”，还必须建立在“源语言确实发生了遗忘”的基础上。如果所有语言都没忘（d_k 均为 0），标准差也为 0，但这属于遗忘失败，而非一致性完美。

**来源标注**：**本文自创扩展**。这一指标专门比较各语言相对遗忘率的离散程度，属于多语言一致性问题下的新设计，不是 TOFU 或 Harry Potter 的原始指标。

##### 指标3：方向性不对称指标

**计算方式**：

- **样本类型**：问答型样本
- `A_(L_a,L_b)`：语言 `L_a` 和语言 `L_b` 之间的方向性不对称指标
- `T_(L_a→L_b)`：从语言 `L_a` 到语言 `L_b` 的迁移率
- `T_(L_b→L_a)`：从语言 `L_b` 到语言 `L_a` 的迁移率

```text
A_(L_a,L_b) = | T_(L_a→L_b) - T_(L_b→L_a) |
方向性不对称指标 = | 语言A到语言B的迁移率 - 语言B到语言A的迁移率 |
```

**动机**：分析跨语言迁移是否具有方向性。

**来源标注**：**本文自创扩展**。该指标用于判断跨语言遗忘迁移是否具有方向性，是多语言场景特有的问题，在 TOFU 与 Harry Potter 中都不存在。

#### B. 鲁棒性层

##### 指标4：跨语言自然表达稳健遗忘率

**计算方式**：

- **样本类型**：问答型样本
- `F_natural`：跨语言自然表达稳健遗忘率
- `Acc_after^(natural)`：遗忘后模型在自然表达样本集上的准确率

```text
F_natural = 1 - Acc_after^(natural)
自然表达稳健遗忘率 = 自然表达下未正确回答的样本数 / 自然表达样本总数
```

**动机**：验证共同遗忘发生在语义层，而不是模板层。

**来源标注**：**本文自创扩展（吸收 TOFU / Harry Potter 的稳健泄漏检测思路）**。它继承了“换表达后还能不能恢复”的思想，但正式面向跨语言自然表达场景，是本文的新扩展。

##### 指标5：桥接语言恢复率

**计算方式**：

- **样本类型**：问答型样本
- `R_bridge`：桥接语言恢复率
- `Acc_after^(bridge)`：遗忘后模型在桥接测试样本集上的准确率

```text
R_bridge = Acc_after^(bridge)
桥接恢复率 = 通过另一语言重新恢复目标知识的样本数 / 桥接测试样本总数
```

**动机**：检验共享知识是否仍可通过其他语言绕路恢复。

**来源标注**：**更像 Harry Potter，并由本文做多语言扩展**。其核心是测试目标知识能否通过另一条提示路径被重新唤醒，这与 Harry Potter 的泄漏探针精神最接近；区别在于本文把“绕路恢复”扩展到了跨语言桥接。

#### C. 机制层

##### 指标6：跨语言共享表征削弱程度

**计算方式**：

- **样本类型**：问答型样本
- `h_before^(L_s)`、`h_before^(L_t)`：遗忘前模型在源语言和目标语言下的隐层表示
- `h_after^(L_s)`、`h_after^(L_t)`：遗忘后模型在源语言和目标语言下的隐层表示
- `Sim_before = cos(h_before^(L_s), h_before^(L_t))`：遗忘前跨语言表征相似度
- `Sim_after = cos(h_after^(L_s), h_after^(L_t))`：遗忘后跨语言表征相似度
- `ΔSim_shared`：跨语言共享表征削弱程度

```text
ΔSim_shared = Sim_before - Sim_after
共享表征削弱程度 = 遗忘前跨语言表征相似度 - 遗忘后跨语言表征相似度
```

**动机**：验证遗忘是否作用于跨语言共享知识表征。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 原始评测都没有直接度量“跨语言共享表征”是否被削弱；该指标是多语言机制层分析下的新设计。

##### 指标7：跨语言答案偏好变化

**计算方式**：

- **样本类型**：问答型样本
- `P_before^(k)`：遗忘前模型在语言 `k` 对正确答案的条件概率
- `P_after^(k)`：遗忘后模型在语言 `k` 对正确答案的条件概率
- `ΔP^(k)`：语言 `k` 的跨语言答案偏好变化

```text
ΔP^(k) = P_before^(k) - P_after^(k)
跨语言答案偏好变化 = 遗忘前语言k的正确答案概率 - 遗忘后语言k的正确答案概率
```

**动机**：表面输出下降不等于内部偏好同步下降。

**来源标注**：**TOFU + Harry Potter 吸收，本文多语言扩展**。TOFU 和 Harry Potter 都关注正确答案或关键 token 的概率偏好；本文把这一思想迁移到跨语言 setting，观察不同语言中内部偏好是否同步下降。

#### D. 副作用层

##### 指标8：非目标语言误删率

先定义：

- **样本类型**：问答型样本
- `R_nontarget_lang`：非目标语言知识保留率
- `Acc_after^(nontarget_lang)`：遗忘后模型在非目标语言样本集上的准确率
- `E_nontarget_lang`：非目标语言误删率

```text
R_nontarget_lang = Acc_after^(nontarget_lang)
非目标语言知识保留率 = 非目标语言知识仍正确回答的样本数 / 非目标语言样本总数
```

再定义：

```text
E_nontarget_lang = 1 - R_nontarget_lang
误删率 = 1 - 非目标语言知识保留率
```

**动机**：共同遗忘不等于跨语言大面积误删。

**来源标注**：**本文自创扩展（延续 TOFU 的 utility 精神）**。TOFU 强调非目标能力保持，但不涉及“非目标语言”这一边界；本文把副作用检查细化到跨语言层面。

##### 指标9：多语言一般能力保持率

**计算方式**：

- **样本类型**：文本补全/续写型样本
- `S_before`：遗忘前模型在某项通用任务上的得分
- `S_after`：遗忘后模型在同一任务上的得分
- `R_multilingual`：多语言一般能力保持率

```text
R_multilingual = S_after / S_before
多语言能力保持率 = 遗忘后多语言通用任务得分 / 遗忘前多语言通用任务得分
```

**动机**：防止模型通过整体退化制造“大家都忘了”的假象。

**来源标注**：**更像 TOFU，并由本文做多语言扩展；同时借鉴 MUSE §3.1 C4**。该指标延续 TOFU 的 model utility 主轴，只是把一般能力检查从单语扩展到了多语言场景；从部署视角看，它也直接对应 MUSE 的 **Utility preservation**。

#### E. 对照层

##### 指标10：目标-对照跨语言迁移差值

设：

- **样本类型**：问答型样本
- `T_target,L_s→L_t`：目标集迁移率
- `T_control,L_s→L_t`：对照集迁移率
- `ΔT_target-control`：目标-对照跨语言迁移差值

则：

```text
ΔT_target-control = T_target,L_s→L_t - T_control,L_s→L_t
目标-对照跨语言迁移差值 = 目标集跨语言迁移率 - 对照集跨语言迁移率
```

**动机**：验证跨语言共同遗忘是否特异性地发生在目标 common goal 上，而不是同类非目标知识也一起下降。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 都没有“目标集与对照集在跨语言迁移上相减”的设计；该指标用于证明共同遗忘确实集中在目标 common goal 上。

##### 指标11：目标-对照桥接恢复差值

设：

- **样本类型**：问答型样本
- `B_target`：目标集桥接恢复率
- `B_control`：对照集桥接恢复率
- `ΔB_target-control`：目标-对照桥接恢复差值

则：

```text
ΔB_target-control = B_target - B_control
目标-对照桥接恢复差值 = 目标集桥接恢复率 - 对照集桥接恢复率
```

可报告二者差异或分别报告二者水平。

**动机**：验证被切断的是目标共享知识，而不是所有跨语言访问路径。

**来源标注**：**本文自创扩展（吸收 Harry Potter 的泄漏探针思路）**。Harry Potter 强调目标知识是否仍会被重新引出；本文进一步比较目标与对照在桥接恢复上的差异，以检验目标特异性。

### 8.4 问题二的判定标准

只有当下面同时满足时，才认为 common unlearning goals 上实现了跨语言一致遗忘：

1. 源语言中目标知识下降  
2. 其他语言中的对应知识也显著下降  
3. 各语言下降趋势总体一致  
4. 自然表达下仍然失效  
5. 桥接语言无法轻易恢复  
6. 非目标语言知识和多语言能力基本保持  
7. 共同遗忘主要发生在目标集上，而对照集不表现出同等程度的共同下降  

---

## 九、问题三：对于 culture-specific unlearning goals，遗忘是否被限制在目标边界内

### 9.1 评价动机

culture-specific unlearning goals 依赖于特定文化、语言语境和社会背景，因此理想行为不是“跨语言一起忘”，而是：

> **在目标文化中遗忘，在其他文化中保持不忘。**

### 9.2 使用的数据集

- 目标遗忘集（目标文化子集）
- 对照集（跨文化版）
- 边界保留集
- 跨语言迁移集（非目标部分）
- 跨语言桥接恢复集
- 通用能力集

### 9.3 评价指标、计算方式与动机

#### A. 结果层

##### 指标1：目标边界删除成功率

**计算方式**：

- **样本类型**：问答型样本
- `F_boundary_target`：目标边界删除成功率
- `Acc_after^(boundary_target)`：遗忘后模型在目标文化目标样本集上的准确率

```text
F_boundary_target = 1 - Acc_after^(boundary_target)
目标边界删除成功率 = 目标文化中未正确回答的样本数 / 目标文化目标样本总数
```

**动机**：边界控制的前提是先命中目标。

**来源标注**：**本文自创扩展（受 TOFU 目标删除思路启发）**。它保留了“目标是否被删掉”这一基本问题，但把评测对象改成 culture-specific 边界内部的目标知识。

##### 指标2：边界外知识保留率

**计算方式**：

- **样本类型**：问答型样本
- `R_boundary_out`：边界外知识保留率
- `Acc_after^(boundary_out)`：遗忘后模型在边界外非目标样本集上的准确率

```text
R_boundary_out = Acc_after^(boundary_out)
边界外知识保留率 = 边界外非目标知识仍正确回答的样本数 / 边界外样本总数
```

**动机**：直接对应“在另外一种文化中不要忘”。

**来源标注**：**TOFU 吸收，本文扩展**。TOFU 关注 retain / utility；本文把这种“非目标保持”进一步具体化为边界外、跨文化、跨语言知识是否被保留。

#### B. 鲁棒性层

##### 指标3：别名/翻译/借词泄漏率

**计算方式**：

- **样本类型**：问答型样本
- `L_variant`：别名/翻译/借词泄漏率
- `Acc_after^(variant)`：遗忘后模型在变体测试样本集上的准确率

```text
L_variant = Acc_after^(variant)
泄漏率 = 通过变体表达重新恢复目标知识的样本数 / 变体测试样本总数
```

**动机**：检验边界是否经得起表达变体和跨文化路径的挑战。

**来源标注**：**更像 Harry Potter，并由本文做文化/多语言扩展**。Harry Potter 的 familiarity 检测关心模型是否仍暴露目标域特有内容；本文将这种泄漏探测具体化为别名、翻译和借词路径。

#### C. 机制层

##### 指标4：邻近概念误伤强度

- **样本类型**：问答型样本
- `P_before^(i)`：遗忘前模型对正确答案的条件概率
- `P_after^(i)`：遗忘后模型对正确答案的条件概率
- `h_before^(i)`：问题 `q_i` 在遗忘前模型中的隐层表示
- `h_after^(i)`：问题 `q_i` 在遗忘后模型中的隐层表示
- `ΔP_neighbor`：邻近概念误伤强度（概率形式）
- `ΔRepr_neighbor`：邻近概念表征变化（表示形式）
- `N`：邻近概念样本总数
- `cos(a, b)`：向量 a 和 b 的余弦相似度

概率形式：

```text
ΔP_neighbor = (1/N) * Σ_i [ P_before^(i) - P_after^(i) ]
邻近概念误伤强度 = 邻近概念样本的平均概率下降幅度
```

表示形式（使用余弦距离衡量变化）：

```text
ΔRepr_neighbor = (1/N) * Σ_i [ 1 - cos(h_before^(i), h_after^(i)) ]
邻近概念表征变化 = 邻近概念样本遗忘前后表征的平均余弦距离
```

**动机**：检验删除是否外溢到语义邻域。距离越大，说明误伤越严重。

**来源标注**：**本文自创扩展**。TOFU 与 Harry Potter 都未把“语义邻域的 collateral damage”写成独立概率/表征指标；本文专门加入该项以测量边界外溢。

##### 指标5：跨语言非目标表征保持程度

**计算方式**：

- **样本类型**：问答型样本
- `h_before^(i)`：问题 `q_i` 在遗忘前模型中的隐层表示
- `h_after^(i)`：问题 `q_i` 在遗忘后模型中的隐层表示
- `E[cos(h_before^(i), h_random)]`：遗忘前表征与一批随机样本表征的期望余弦相似度
- `R_repr_nontarget`：跨语言非目标表征保持程度
- `N`：非目标样本总数
- `cos(a, b)`：向量 a 和 b 的余弦相似度

```text
R_repr_nontarget = (1/N) * Σ_i [ cos(h_before^(i), h_after^(i)) - E[cos(h_before^(i), h_random)] ]
非目标表征保持程度 = 非目标样本遗忘前后表征的平均余弦相似度 - 遗忘前表征与随机表征的期望余弦相似度
```

**动机**：从机制层验证“另外一种文化中不要忘”。

**来源标注**：**本文自创扩展**。这是一个面向 culture-specific 边界控制的机制层指标，TOFU 与 Harry Potter 原始评测中均无直接对应项。

#### D. 副作用层

##### 指标6：非目标文化知识保留率

**计算方式**：

- **样本类型**：问答型样本
- `R_nontarget_culture`：非目标文化知识保留率
- `Acc_after^(nontarget_culture)`：遗忘后模型在非目标文化样本集上的准确率

```text
R_nontarget_culture = Acc_after^(nontarget_culture)
非目标文化知识保留率 = 非目标文化知识仍正确回答的样本数 / 非目标文化样本总数
```

**动机**：直接衡量跨文化误删程度。

**来源标注**：**TOFU 吸收，本文扩展；同时借鉴 MUSE §3.1 C4**。其基本精神仍是 TOFU 式的 utility / retain 检查，但本文把对象进一步限定为“非目标文化知识”；从框架角色上，它也属于 MUSE 的 **Utility preservation** 延展。

##### 指标7：综合选择性得分（H-Score）

设：

- **样本类型**：问答型样本
- `F_boundary_target`：目标边界删除成功率
- `R_boundary_out`：边界外知识保留率
- `H-Score`：综合选择性得分

则：

```text
H-Score = 2 * (F_boundary_target * R_boundary_out) / (F_boundary_target + R_boundary_out)
综合选择性得分 (H-Score) = 2 * (目标边界删除成功率 * 边界外知识保留率) / (目标边界删除成功率 + 边界外知识保留率)
```

**动机**：借鉴 F1-Score 的调和平均数思想，综合衡量“删得掉”和“保得准”。只有当目标删得干净且边界外保得完好时，得分才会高。这避免了因模型随机波动导致边界外损伤程度为负数或极小值时引发的数值爆炸问题。

**来源标注**：**本文自创扩展**。这是本文为同时综合“删得掉”和“保得准”两方面表现而设计的综合指标，不属于 TOFU 或 Harry Potter 的原始指标。

##### 指标8：一般能力保持率

**计算方式**：

- **样本类型**：文本补全/续写型样本
- `S_before`：遗忘前模型在某项通用任务上的得分
- `S_after`：遗忘后模型在同一任务上的得分
- `R_general`：一般能力保持率

```text
R_general = S_after / S_before
一般能力保持率 = 遗忘后通用任务得分 / 遗忘前通用任务得分
```

**动机**：防止通过整体能力退化换取局部看似成功的边界删除。

**来源标注**：**更像 TOFU + 借鉴 MUSE §3.1 C4**。该指标延续 TOFU 对整体可用性的重视，在 culture-specific 场景下继续作为副作用控制项保留；同时与 MUSE 的 **Utility preservation** 保持一致。

#### E. 对照层

##### 指标9：目标-对照边界删除差值

设：

- **样本类型**：问答型样本
- `F_target`：目标文化目标知识的删除成功率
- `F_control`：对照文化内容的删除成功率
- `ΔF_boundary`：目标-对照边界删除差值

则：

```text
ΔF_boundary = F_target - F_control
目标-对照边界删除差值 = 目标文化目标知识的删除成功率 - 对照文化内容的删除成功率
```

**动机**：验证删除确实集中在目标文化边界内，而不是相似文化内容一起下降。

**来源标注**：**本文自创扩展**。该指标将对照思想显式引入边界控制问题，用于证明删除主要发生在目标文化边界内，而不是相似文化内容一起下降。

##### 指标10：目标-对照表征保持差值

设：

- **样本类型**：问答型样本
- `R_control-repr`：对照文化知识的表征保持程度
- `R_target-repr`：目标文化知识的表征保持程度
- `ΔR_repr`：目标-对照表征保持差值

则：

```text
ΔR_repr = R_control-repr - R_target-repr
目标-对照表征保持差值 = 对照文化知识的表征保持程度 - 目标文化知识的表征保持程度
```

**动机**：验证边界外表征比目标表征更稳定，从而支持边界控制成立。

**来源标注**：**本文自创扩展**。这是边界控制场景下的表征层对照指标，TOFU 与 Harry Potter 原始评测均未提供直接对应形式。

### 9.4 问题三的判定标准

只有当下面同时满足时，才认为 culture-specific unlearning goals 上实现了边界受控遗忘：

1. 目标文化中的目标知识显著下降  
2. 其他文化中的非目标知识基本保持  
3. 别名、翻译、借词路径不造成明显泄漏  
4. 邻近概念不出现明显误伤  
5. 一般能力保持稳定  
6. 目标文化中的目标知识比结构相似的对照文化知识表现出更强的删除效应，而对照文化知识保持相对稳定

## 十、最终汇报方式

### 第一阶段：问题一报告

回答：目标知识是否真正被遗忘。

### 第二阶段：问题二报告

回答：对于 common goals，是否实现了“一个语言忘了，其他语言也忘了”。

### 第三阶段：问题三报告

回答：对于 culture-specific goals，是否实现了“在一种文化中忘了，而在另外一种文化中不要忘”。

### 第四阶段：部署与安全性报告

回答：该方法是否同时满足逐字复现控制、隐私泄漏控制、不同 forget 规模下的可扩展性，以及连续遗忘请求下的可持续性。

## 十一、总框架总结

> 本研究的评价框架以三个问题为主轴展开：首先验证目标知识是否被真实遗忘，而非仅在表面输出上失效；其次针对 common unlearning goals，验证某一语言中的遗忘是否会在其他语言中表现为一致的共同遗忘；最后针对 culture-specific unlearning goals，验证目标文化中的知识被遗忘后，其他文化或其他语言中的非目标知识是否能够保持不忘。围绕这三个问题，评价指标分别从结果层、鲁棒性层、机制层、副作用层与对照层构建，并结合目标遗忘集、对照集、语义变体集、跨语言迁移集、跨语言桥接恢复集、边界保留集、通用能力集和 Holdout 集等多类测试数据，对方法的真实性、一致性、边界控制能力以及目标特异性进行系统验证。与此同时，本文进一步吸收 MUSE 的双主体评价思想，将逐字复现残留度、隐私泄漏程度、可扩展性与可持续性作为框架级补充维度纳入统一报告流程，使该框架不仅能够回答“是否遗忘成功”，还能够进一步回答“这种遗忘是否足够安全、可部署、可持续”。
